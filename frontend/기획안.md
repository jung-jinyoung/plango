## 1. 서비스 목적

### 한 줄 정의

> 넓은 화면(Web Service · For Wide Screens)을 전제로, 일정 관리부터 월간·주간 목표, 회고까지 하나의 화면에서 잇는 AI 기반 개인 일정 플래너

### 목적을 구성하는 3가지 근거

**① 시장 공백 해결**
기존 서비스는 4개 유형(일정 기록형, AI 스케줄링형, 유연 워크스페이스형, 모바일 데일리 플래너형)으로 나뉘지만, 어느 것도 "넓은 화면 + AI 효율성 + 자유도"를 동시에 갖추지 못했습니다. Plango는 포지셔닝 맵 상 유일하게 우상단(넓은 화면·높은 효율성)에 위치합니다.

**② 사용자 페인포인트 해소**

- 재택근무 직장인(김도윤, 32세): 갑작스러운 일정 변경, 우선순위 파악 어려움, 도구의 전체 흐름 파악 불가
- 갓생 지망생(대학원생, 이서연, 27세): 노션(목표)과 다이어리(기록)의 도구 분리, 매달 목표 정리 위치 혼란, 패턴 파악 어려움

두 페르소나 모두 "계획-실행-회고가 하나로 이어지지 않는 문제"를 공통으로 겪고 있으며, 이것이 서비스의 핵심 존재 이유입니다.

**③ 검증된 이론적 근거**

- 목표를 적고 정기적으로 검토한 사람은 42% 더 높은 목표 달성률 (Dominican University 연구)
- 주간 계획·회고가 미완료 작업과 반추를 줄이고 인지적 유연성을 높임 (JOOP, 2023, 지식노동자 208명 대상)

### 서비스 정체성

- **이름**: Plango (Plan + Go의 결합)
- **로고**: 플라밍고 모티브 — 한 발로 균형 잡고 다음 걸음을 준비하는 모습에서 착안, "목표를 향해 한 걸음씩 나아가는 여정"을 상징
- **슬로건**: "Plan it, Live it, Reflect on it." — 계획(Plan)-실행(Live)-회고(Reflect)의 순환 구조를 표현

## 2. 핵심 기능 (Key Feature)

PDF상 2개 대분류, 총 6개 세부 기능으로 정리되어 있습니다.

### Feature 1. AI 우선순위 분석을 통한 하루 일정 자동 구성

| 세부 기능         | 설명                                                                                            |
| ----------------- | ----------------------------------------------------------------------------------------------- |
| 통합 캘린더 뷰    | 넓은 화면 전용, 월간·주간·일간을 한 화면에서 확인                                               |
| 목표 상시 노출    | 사이드 패널에 이번 달·이번 주 목표 상시 노출                                                    |
| AI 하루 계획 추천 | 순서 없이 적은 할 일을 소요시간·마감일·목표 연관성 기준으로 분석해 우선순위·시간 블록 자동 추천 |
| 유연한 재배치     | 드래그 앤 드롭 재배치, 미완료 항목은 다음 날 또는 주간 목표로 이월 제안                         |

### Feature 2. AI 데이터 분석 기반 주간·월간 회고 자동 생성

| 세부 기능           | 설명                                                |
| ------------------- | --------------------------------------------------- |
| 통합 기록 시스템    | 계획·실행·회고를 하나의 웹 화면에서 처리            |
| 목표 계층 연결      | 일간-주간-월간 목표를 태그로 연결, 역방향 추적 가능 |
| 주간 회고 자동 생성 | 완료율·미완료 패턴을 AI가 분석해 리포트 자동 생성   |
| 월간 요약 리포트    | 4주간 회고를 종합해 목표 달성률 시각화              |

### 6가지 Needs-Solution 대응 (Key Feature의 근거)

| 카테고리    | 기능                                |
| ----------- | ----------------------------------- |
| Clarity     | 월간·주간·일간을 한 화면에서 확인   |
| Priority    | 목표와 일정을 구분해서 볼 수 있음   |
| Efficiency  | 순서 없이 적어도 자동 우선순위 배치 |
| Flexibility | 일정 변경 시 즉시 재배치            |
| Integration | 계획·실행·회고를 한 화면에서 기록   |
| Insight     | 매주 무엇을 해냈는지 자동 확인      |

## 3. User Flow

PDF의 "매일 루프" 다이어그램(월간 목표 → 주간 목표 → 일간 루프 → 주간 회고 → 월간 회고)을 단계별로 풀어썼습니다.

### 진입 흐름

```
1. 월간 목표 설정
   └─ 이번 달 방향 설정, 목표 입력
        ↓
2. 주간 목표 설정
   └─ 월간 목표를 바탕으로 이번 주 우선순위 조정
        ↓
```

### 일간 루프 (매일 반복)

```
3. 할 일 입력
   └─ 순서·형식 제한 없이 자유롭게 입력 (Free-form, Keyboard Input)
        ↓
4. AI 추천
   └─ 예상 소요시간, 분류 등 기준으로 자동 정렬 및 일정 추천 (Auto-Priority)
        ↓
5. 일정 확정/재배치
   └─ 드래그로 일정 자유 조정 (Real-time Adjust)
        ↓
6. 실행 & 기록
   └─ 완료 체크
        ↓
   [일정 변동 시] → 드래그로 재조정 또는 할 일 리스트로 이동
        ↓
   (3번으로 복귀, 매일 반복)
```

### 주간 순환

```
7. 주간 회고
   └─ AI가 완료율·패턴 분석 → 회고 리포트 자동 생성 (Auto-Reflect)
        ↓
   (2번 주간 목표 설정으로 복귀 — "다음 주 반영")
```

### 월간 순환

```
8. 월간 회고
   └─ 4주간 회고 종합, 목표 달성률 시각화, AI 피드백 제공
        ↓
   (1번 월간 목표 설정으로 복귀 — "다음 달 반영")
```

### 핵심 특징

- 일간(매일) → 주간(매주) → 월간(매달) 순으로 반복 주기가 커지는 **3중 중첩 순환 구조**
- 각 회고는 반드시 상위 목표 설정 단계로 되돌아가 "다음 계획에 반영"됨
- PDF 원문 표현: _"이 루프가 반복될수록, 계획은 매번 처음부터 다시 세우는 것이 아니라 점점 더 자신에게 맞게 다듬어집니다."_

## 4. Screen Inventory (전체 화면 목록)

PDF에 명시된 기능을 화면 단위로 분해하고, UX 관점에서 누락되었을 가능성이 있는 화면을 **[제안]** 표시로 함께 정리했습니다.

### A. 온보딩 / 계정

| 화면                           | 설명                           |
| ------------------------------ | ------------------------------ |
| A1. 랜딩 페이지                | 서비스 소개, 슬로건, CTA       |
| A2. 회원가입/로그인            | 계정 생성, 소셜 로그인         |
| A3. 온보딩 (첫 목표 설정 유도) | 첫 진입 시 월간 목표 입력 유도 |

### B. 핵심 캘린더/대시보드

| 화면                        | 설명                                       |
| --------------------------- | ------------------------------------------ |
| B1. 통합 대시보드 (월간 뷰) | 월간 캘린더 + 사이드 목표 패널, 뷰 전환 탭 |
| B2. 주간 뷰                 | 주간 캘린더, 이번 주 목표 패널             |
| B3. 일간 뷰                 | 하루 타임라인, 할 일 리스트                |
| B4. 뷰 전환 UI              | 월간/주간/일간 탭 전환                     |

### C. 목표 관리

| 화면                    | 설명                                      |
| ----------------------- | ----------------------------------------- |
| C1. 월간 목표 입력/수정 | 월간 목표 추가, 진행률 표시               |
| C2. 주간 목표 입력/수정 | 주간 목표 추가, 월간 목표와 태그 연결     |
| C3. 목표 계층 트리 뷰   | 월간→주간→일간 역방향 추적, 아코디언 펼침 |

### D. 일간 계획 (AI)

| 화면                            | 설명                                                                             |
| ------------------------------- | -------------------------------------------------------------------------------- |
| D1. 할 일 더미 입력             | 순서 없이 할 일 작성                                                             |
| D2. AI 추천 결과 화면           | 우선순위·시간 블록 추천안 표시                                                   |
| D3. 추천안 확정/재배치 (드래그) | 타임라인 위에서 드래그 조정                                                      |
| D4. 완료 체크 & 기록            | 완료 여부 체크, 메모 입력                                                        |
| D5. 미완료 항목 이월 처리       | 다음 날/주간 목표로 이월 선택                                                    |
| D6. 일정 충돌 알림              | 갑작스러운 일정 추가 시 재배치 안내 (페르소나1의 "예고 없이 끼어드는 회의" 대응) |

### E. 회고

| 화면                       | 설명                                                             |
| -------------------------- | ---------------------------------------------------------------- |
| E1. 주간 회고 리포트       | 완료율, 패턴 분석, AI 텍스트 요약                                |
| E2. 월간 회고 리포트       | 4주 종합, 목표 달성률 시각화, AI 피드백                          |
| E3. 회고 히스토리 아카이브 | 지난 주간/월간 회고를 모아보는 화면 (누적 데이터 확인 니즈 대응) |
